После нескольких недель работы выпустил обновление для ZettaDNS.com. Что было сделано:

- Кодовая база исправлена и проверена под python версии 3
- Изменены тарифы
- Исправлено API
- Обновлена библиотека PyCloudNS

## Подробнее по каждому пункту

**Python 3** - по большей части это подстраховка на будущее, чтобы не
исправлять код потом, так как поддержка python версии 2 заканчивается в
следующем году.

**Тарифы** - Новая редакция тарифов не изменяет цены на расширенную подписку,
но добавляет дополнительные возможности стандартной подписке. Например, доступ
к API, теперь его могут использовать все пользователи сервиса.

**API** - исправлены ошибки при работе с API, добавлены новые методы.

**PyCloudNS** - обновлена библиотека исправлено на новую версию API и добавлены
дополнительные методы, до этого использовалось нестабильная версия API.
Подготовлен pip-пакет. Подробнее можно прочитать на странице:
https://github.com/zettadns/PyCloudNS
